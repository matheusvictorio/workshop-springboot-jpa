# 🚀 Workshop Spring Boot JPA

[![Java](https://img.shields.io/badge/Java-17-blue.svg)](https://www.oracle.com/java/)
[![Spring Boot](https://img.shields.io/badge/Spring%20Boot-3.x-brightgreen.svg)](https://spring.io/projects/spring-boot)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

Este projeto é um exemplo prático de um Web Service desenvolvido com **Spring Boot** e **JPA/Hibernate**, com o objetivo de demonstrar a construção de APIs RESTful utilizando boas práticas de desenvolvimento.

---

## 🧰 Tecnologias Utilizadas

- Java 17  
- Spring Boot 3.x  
- Spring Data JPA  
- Hibernate  
- Maven  
- H2 Database (em memória)

---

## ⚙️ Como Executar o Projeto

### ✅ Pré-requisitos

- Java 17 ou superior instalado  
- Maven instalado

### ▶️ Passos

```bash
# Clone o repositório
git clone https://github.com/matheusvictorio/workshop-springboot-jpa.git

# Acesse a pasta do projeto
cd workshop-springboot-jpa

# Execute a aplicação
./mvnw spring-boot:run

# Acesse o projeto
http://localhost:8080
```
---

###  ✅ Funcionalidades
- [x] Cadastro e listagem de usuários  
- [x] Cadastro de pedidos e produtos  
- [x] Relacionamentos entre entidades (OneToMany, ManyToOne)  
- [x] Persistência com JPA e Hibernate  
- [x] Banco de dados H2 configurado para testes
